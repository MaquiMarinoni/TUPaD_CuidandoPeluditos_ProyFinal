# Frontend | Cuidando Peluditos

En este directorio se organiza la capa de presentación de la plataforma, diseñada bajo una interfaz tradicional responsiva renderizada desde el servidor mediante plantillas Jinja2 y estilizada con Bootstrap 5, reutilizando la identidad visual y componentes validados del prototipo original.

## Estructura de carpetas
* `templates/`: Vistas y plantillas HTML organizadas por módulo funcional (`auth`, `mascotas`, `cuidadores`, `solicitudes`).
* `static/css/`: Hojas de estilo personalizadas para cada vista.
* `static/js/`: Lógica del lado cliente para validaciones interactivas de formularios y filtros dinámicos.
* `static/img/`: Recursos gráficos, ilustraciones, íconos y banners del sistema.

## Tecnologías
* HTML5 / CSS3
* Bootstrap 5.3 (diseño responsivo móvil y escritorio)
* JavaScript ES6 (validaciones del lado cliente)
