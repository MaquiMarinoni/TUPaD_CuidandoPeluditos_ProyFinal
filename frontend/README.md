# Frontend | Cuidando Peluditos

Este directorio contiene la estructura inicial de la capa de presentación de **Cuidando Peluditos**. La interfaz propuesta utilizará plantillas Jinja2 renderizadas desde el servidor y Bootstrap 5 para adaptar las pantallas a distintos dispositivos.

## Estructura de carpetas
* `templates/`: Carpeta destinada a las vistas y plantillas HTML. Se prevé organizarlas por módulo funcional (`auth`, `mascotas`, `cuidadores`, `solicitudes`).
* `statics/`: Carpeta destinada a los recursos de la interfaz. Se prevé incorporar subcarpetas para hojas de estilo (`css/`), JavaScript (`js/`) e imágenes (`img/`).

## Tecnologias
* HTML5 y CSS3.
* Bootstrap 5.3 para el diseño responsivo.
* JavaScript ES6 para interacciones y validaciones del lado cliente.
* Jinja2 para las plantillas renderizadas desde Flask.
